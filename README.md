# GlobalMart – E-Commerce Sales & Business Intelligence Dashboard

## Project Overview

GlobalMart is an interactive Power BI dashboard designed to analyze e-commerce sales performance and generate business insights.

The project explores sales trends, product performance, customer behavior, and geographical distribution to support data-driven business decisions.

## Tech Stack

- Power BI
- Power Query
- DAX
- Excel / CSV
- GitHub

## Dashboard Pages

1. **Sales Overview** – Overall business performance and KPIs.
2. **Product Analysis** – Product and category performance.
3. **Customer Analysis** – Customer segments and purchasing patterns.
4. **Geographical Analysis** – Sales distribution across locations.
5. **Sales Trends** – Time-based sales analysis.

2. Open it using Microsoft Power BI Desktop.
3. Interact with the dashboard using the available filters and slicers.
